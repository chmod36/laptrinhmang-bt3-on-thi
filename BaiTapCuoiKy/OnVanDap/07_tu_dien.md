# 07 – Từ điển

Từ tiếng Anh gặp trong code và trong câu hỏi của thầy. Giữ nguyên tiếng Anh vì thầy sẽ dùng đúng những từ này. Xếp theo chữ cái.

| Từ | Đọc | Nghĩa đen | Nghĩa trong bài | Ví dụ đời thường |
|---|---|---|---|---|
| boolean | /ˈbuː.li.ən/ "bu-li-ần" | (tên nhà toán học Boole) | kiểu đúng/sai: `true`/`false` | công tắc bật/tắt |
| buffer | /ˈbʌf.ər/ "bắp-phơ" | vùng đệm | thùng chứa tạm gói tin nhận được, 8192 byte | hộp thư trước cửa nhà |
| byte | /baɪt/ "bai" | (đơn vị) | đơn vị dữ liệu nhỏ nhất mạng chở được | từng viên gạch |
| case | /keɪs/ "kây-x" | trường hợp | một nhánh trong `switch` | "bấm phím 1" ở tổng đài |
| catch | /kætʃ/ "két-ch" | bắt | bắt lỗi để xử lý | người cứu hỏa nghe còi |
| class | /klɑːs/ "clát" | loại, lớp | cái khuôn mô tả một loại đồ vật | khuôn bánh |
| client | /ˈklaɪ.ənt/ "clai-ần" | khách hàng | chương trình có cửa sổ, đi hỏi Server | khách gọi món |
| common | /ˈkɒm.ən/ "com-mần" | chung | gói chứa code dùng chung cho hai bên | bảng nội quy dán ở cả hai quầy |
| compile | /kəmˈpaɪl/ "cơm-pai" | biên soạn | dịch code người viết thành code máy chạy (`javac`) | dịch sách sang tiếng máy |
| constructor | /kənˈstrʌk.tər/ "cần-xtrắc-tơ" | người xây dựng | hàm trùng tên class, chạy một lần khi tạo object | lúc khai trương cửa hàng |
| datagram | /ˈdeɪ.tə.ɡræm/ "đây-tơ-gram" | bức điện dữ liệu | một gói tin UDP (`DatagramPacket`) | tấm bưu thiếp |
| default | /dɪˈfɔːlt/ "đi-phôn" | mặc định | nhánh còn lại của `switch` | "bấm phím khác để gặp nhân viên" |
| exception | /ɪkˈsep.ʃən/ "ích-xép-sần" | ngoại lệ | tín hiệu "có lỗi" Java ném ra | tiếng còi báo cháy |
| final | /ˈfaɪ.nəl/ "phai-nồ" | cuối cùng | không được thay đổi nữa | chữ khắc trên đá |
| foreign key | /ˈfɒr.ən kiː/ "pho-rần ki" | khóa ngoại | mã thuốc trỏ tới mã công dụng | sinh viên ghi mã lớp |
| handle | /ˈhæn.dəl/ "hen-đồ" | xử lý, tay cầm | hàm nhận và xử lý mọi lệnh ở Server | nhân viên tiếp nhận hồ sơ |
| host | /həʊst/ "hâu-xt" | chủ nhà | địa chỉ máy chạy Server | địa chỉ tòa nhà |
| IP | "ai-pi" | Internet Protocol | địa chỉ của máy trên mạng | địa chỉ nhà |
| JDK | "giây-đi-cây" | Java Development Kit | bộ đồ nghề để dịch và chạy Java | hộp đồ nghề thợ |
| lambda | /ˈlæm.də/ "lam-đa" | chữ λ | hàm viết gọn không tên: `x -> …` | tờ giấy dặn việc |
| List | /lɪst/ "lít" | danh sách | dãy phần tử có thứ tự | hàng người xếp hàng |
| localhost | /ˈləʊ.kəl.həʊst/ "lâu-cồ hâu-xt" | máy chủ tại chỗ | chính máy này, `127.0.0.1` | "nhà mình" |
| Map | /mæp/ "máp" | bản đồ | danh bạ tra mã ra đồ vật | danh bạ điện thoại |
| method | /ˈmeθ.əd/ "mé-thợt" | phương pháp | hàm, một việc object làm được | công thức nấu ăn |
| null | /nʌl/ "nâu" | không có gì | giá trị rỗng, ví dụ tra không thấy | ô trống |
| object | /ˈɒb.dʒɪkt/ "óp-dếch" | đồ vật | một đồ vật đúc từ class | cái bánh |
| packet | /ˈpæk.ɪt/ "pác-kít" | gói nhỏ | gói tin gửi qua mạng | phong bì thư |
| parse | /pɑːz/ "pa-z" | phân tích câu | đọc chuỗi chữ, tách thành dữ liệu | đọc thư và tách ý |
| port | /pɔːt/ "pót" | cảng, cửa | số cửa trên máy, Server dùng 9876 | số phòng trong tòa nhà |
| private | /ˈpraɪ.vət/ "prai-vợt" | riêng tư | chỉ dùng trong file này | đồ dùng cá nhân |
| protocol | /ˈprəʊ.tə.kɒl/ "prâu-tơ-côn" | nghi thức | quy ước hai bên nói chuyện | mẫu đơn có ô cố định |
| public | /ˈpʌb.lɪk/ "páp-lích" | công khai | file khác dùng được | đồ dùng chung |
| receive | /rɪˈsiːv/ "ri-xiv" | nhận | đứng chờ nhận gói tin | đứng chờ bưu tá |
| record | /ˈrek.ɔːd/ "ré-cợt" | bản ghi | class chỉ chứa dữ liệu | tờ phiếu in sẵn ô |
| request | /rɪˈkwest/ "ri-quét" | lời yêu cầu | tin Client gửi đi | phiếu gọi món |
| response | /rɪˈspɒns/ "ri-xpon" | lời đáp | tin Server gửi lại | món ăn kèm lời nhắn |
| return | /rɪˈtɜːn/ "ri-tơn" | trả về | trả kết quả và kết thúc hàm | trả hàng cho khách |
| send | /send/ "xen-đ" | gửi | gửi gói tin đi | bỏ thư vào hòm |
| server | /ˈsɜː.vər/ "xơ-vơ" | người phục vụ | chương trình giữ dữ liệu, trả lời | bếp / quầy chính |
| socket | /ˈsɒk.ɪt/ "xóc-kít" | ổ cắm | đầu cắm vào mạng để gửi, nhận gói | hòm thư |
| static | /ˈstæt.ɪk/ "xtét-tích" | đứng yên | thuộc về class, không cần tạo object | bảng nội quy treo tường |
| stream | /striːm/ "xtrim" | dòng chảy | băng chuyền xử lý từng phần tử | dây chuyền nhà máy |
| String | /strɪŋ/ "xtrinh" | sợi dây | chuỗi chữ | dòng chữ |
| Swing | /swɪŋ/ "xuynh" | (tên thư viện) | bộ đồ nghề vẽ cửa sổ của Java | bộ Lego |
| SwingWorker | "xuynh guốc-cơ" | người làm việc cho Swing | chạy việc chậm ở phía sau | người chạy việc vặt |
| switch | /swɪtʃ/ "xuých" | công tắc chuyển | chọn việc theo tên lệnh | tổng đài "bấm phím 1…" |
| synchronized | /ˈsɪŋ.krə.naɪzd/ "xinh-crơ-naizd" | được đồng bộ | mỗi lúc chỉ một luồng vào hàm | phòng thay đồ một người |
| TCP | "ti-xi-pi" | Transmission Control Protocol | gửi tin có nối máy, đảm bảo tới nơi | gọi điện thoại |
| thread | /θred/ "thred" | sợi chỉ | một dòng công việc chạy song song | một nhân viên |
| throws | /θrəʊz/ "thrâu-z" | ném | báo trước hàm có thể gây lỗi | biển "cẩn thận trơn trượt" |
| timeout | /ˈtaɪm.aʊt/ "thai-mao" | hết giờ | chờ quá 5 giây thì báo lỗi | hẹn giờ nồi cơm |
| try | /traɪ/ "trai" | thử | thử làm, có lỗi thì `catch` lo | thử làm, hỏng thì có người đỡ |
| UDP | "diu-đi-pi" | User Datagram Protocol | gửi tin không nối máy, không đảm bảo tới nơi | gửi bưu thiếp |
| UTF-8 | "iu-ti-ép tám" | (tên bảng mã) | cách đổi chữ có dấu thành byte | bảng chữ cái chung khi đánh điện |
| void | /vɔɪd/ "voi-đ" | trống rỗng | hàm không trả kết quả gì | làm việc xong không cần báo lại |
