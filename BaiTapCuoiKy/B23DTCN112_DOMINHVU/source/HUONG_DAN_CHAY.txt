QUẢN LÝ THUỐC THEO CÔNG DỤNG (CLIENT – SERVER UDP, CSDL MYSQL) – PHẦN CÁ NHÂN: CHỨC NĂNG XÓA
Sinh viên: Đỗ Minh Vũ – MSSV: B23DTCN112 – Lớp: D23TXCN04-B – Học phần INT1433 Lập trình mạng

Cần có: JDK 17 trở lên; XAMPP (hoặc Laragon); NetBeans (hoặc IntelliJ IDEA).
Server tự tạo database "quanlythuoc", 3 bảng và dữ liệu mẫu ở lần chạy đầu, không cần import gì.
Cấu hình kết nối ở src/main/resources/db.properties (mặc định localhost:3306, root, mật khẩu trống).

A. NetBeans + XAMPP
1. Mở XAMPP Control Panel, nhấn Start ở dòng MySQL.
2. NetBeans: File > Open Project > chọn thư mục "source" (có file pom.xml).
   Lần đầu Maven tải thư viện mysql-connector-j, máy cần có mạng.
3. Source Packages > bt3.server > MedicineServer.java > Run File (Shift+F6).
   Output hiện: "Đã kết nối MySQL" và "Server UDP quản lý thuốc đang lắng nghe tại cổng 9876".
4. Giữ Server chạy, mở bt3.client > MedicineClient.java > Run File (Shift+F6).
   Có thể chạy nhiều Client cùng lúc.
5. Xem dữ liệu: http://localhost/phpmyadmin > database quanlythuoc.

B. IntelliJ IDEA + Laragon
1. Mở Laragon, nhấn Start All (hoặc chỉ MySQL).
2. IntelliJ: File > Open > chọn thư mục "source" > Open as Project > Trust Project.
   File > Project Structure > Project > SDK: chọn JDK 17 trở lên.
3. Mở src/main/java/bt3/server/MedicineServer.java > bấm mũi tên xanh cạnh hàm main > Run.
4. Giữ Server chạy, mở bt3/client/MedicineClient.java > Run.
   Không chạy MedicineServer hai lần (cổng 9876 đã bị chiếm); IntelliJ hỏi thì chọn Stop and Rerun.

Các chức năng
- Tab 1. Thuốc: tìm kiếm (gõ từ 2 ký tự), lọc theo công dụng, thêm, sửa (nhấp đúp), xóa nhiều thuốc
  (giữ Ctrl để chọn nhiều dòng). Thuốc xóa vào Thùng rác; hộp kết quả có nút "Hoàn tác".
- Tab 2. Công dụng: thêm, sửa, xóa. Công dụng còn thuốc thì chọn chuyển thuốc sang công dụng khác
  hoặc xóa vĩnh viễn kèm thuốc.
- Tab 3. Thùng rác: khôi phục, xóa vĩnh viễn, dọn sạch thùng rác.
- Tab 4. Lịch sử xóa: mọi lần xóa/khôi phục (bảng nhat_ky_xoa), lọc theo kết quả và hành động.

Lỗi thường gặp
- "Không kết nối được MySQL": chưa bật MySQL trong XAMPP/Laragon.
- Client báo "Server không phản hồi sau 5 giây": chưa chạy MedicineServer.
- Muốn có lại dữ liệu mẫu: trong phpMyAdmin xóa database quanlythuoc rồi chạy lại Server.
