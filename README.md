# Lập trình mạng – BT3: Quản lý thuốc theo công dụng (UDP + MySQL)

**Ôn cấp tốc: đọc `BaiTapCuoiKy/OnVanDap/00_ON_CAP_TOC.md` trước.**

Chạy trên Kubuntu/Ubuntu:
```bash
cd BaiTapCuoiKy
./chay_bai.sh caidat   # một lần: cài Java 21 + MariaDB (cần sudo, có mạng)
./chay_bai.sh          # bật MySQL, biên dịch, mở Client, chạy Server
./chay_bai.sh client   # mở thêm một Client
./chay_bai.sh reset    # xóa database để lần chạy sau có lại dữ liệu mẫu
```

- `BaiTapCuoiKy/B23DTCN112_DOMINHVU/source/` – code Java (Windows: XAMPP + NetBeans, xem `HUONG_DAN_CHAY.txt`).
- `BaiTapCuoiKy/OnVanDap/` – tài liệu ôn. Các file 01–10 và video viết cho bản cũ (lưu trong RAM, 3 tab); phần giải thích UDP vẫn đúng.
